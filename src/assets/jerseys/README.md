# Ảnh áo đấu cho Gumi (tuỳ chọn)

Thả file ảnh áo ĐÃ TÁCH NỀN (nền trong suốt) vào thư mục này, đặt tên theo đúng `id` của đội.
Ảnh sẽ **tự động** hiện lên thân Gumi (ưu tiên hơn áo vẽ SVG). Thiếu ảnh nào thì đội đó dùng áo SVG.

- Định dạng: `.webp` (khuyên dùng), `.png`, `.jpg` — nền trong suốt.
- Khung hiển thị trên thân Gumi ≈ **96×74** (tỉ lệ ngang), ảnh được canh giữa (`xMidYMid meet`).
  → Crop sát phần áo (bỏ đầu/tay/chân người mẫu), tỉ lệ gần vuông/hơi ngang là đẹp.
- Kích thước khuyên: cạnh ~320–480px cho nét trên màn retina.

## Tên file theo id

Việt Nam (VCS): `gam` · `tsw` · `viking`
Quốc tế: `t1` · `geng` · `hle` · `dk` · `kt` · `jdg` · `blg` · `tes` · `g2` · `fnc`

Ví dụ: `gam.webp`, `t1.webp`, `hle.png`…

> Lưu ý bản quyền: logo/áo đội là tài sản có bản quyền/nhãn hiệu. Chỉ dùng ảnh bạn có quyền
> sử dụng (hàng được cấp phép / tự thiết kế). Bản mặc định trong code là áo cách điệu (màu + tên
> viết tắt), không phải logo gốc.
